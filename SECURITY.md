# Política de Segurança

## Relatando uma vulnerabilidade

Se você encontrar uma vulnerabilidade de segurança no LIAOZIN Otimizador, recomendamos que ela não seja divulgada publicamente antes de ser analisada.

Evite abrir uma Issue pública contendo:

- Vulnerabilidades exploráveis.
- Métodos de execução de código.
- Informações que permitam contornar mecanismos de segurança.
- Credenciais, tokens ou chaves.
- Dados pessoais.
- Detalhes que possam facilitar exploração por terceiros.

Utilize os recursos privados de segurança disponibilizados pelo GitHub ou entre em contato com os mantenedores através de um canal oficial.

## O que informar

Sempre que possível, inclua:

- Versão do LIAOZIN.
- Versão do Windows.
- Descrição do problema.
- Passos necessários para reproduzir o problema.
- Impacto observado.
- Logs relevantes.
- Possível solução, caso conhecida.

Não inclua informações pessoais ou credenciais.

## Segurança do sistema

O LIAOZIN pode executar operações que exigem privilégios administrativos e modificar configurações do Windows.

O projeto segue alguns princípios:

- Não desativar Microsoft Defender.
- Não desativar Microsoft Defender SmartScreen.
- Evitar alterações irreversíveis.
- Preferir configurações por usuário quando possível.
- Informar alterações potencialmente agressivas.
- Permitir restauração das configurações sempre que possível.

## Dependências

O projeto utiliza componentes e recursos disponíveis no Windows e em suas dependências declaradas.

Problemas de segurança relacionados a dependências também devem ser reportados aos mantenedores quando afetarem diretamente o LIAOZIN.

## Divulgação

Após a correção de uma vulnerabilidade, os mantenedores poderão publicar informações sobre o problema e sua correção, quando apropriado.
